## 📊 INFORMAÇÕES RÁPIDAS

### Produto
- **Nome:** Cetose Consciente
- **Tipo:** E-book Digital + Plataforma PWA + IA Especialista
- **Preço:** R$ 27,90 (entrada)
- **Upsells:** Plano Alimentar (R$ 47), Clube Premium (R$ 47/mês)

### Tecnologias Utilizadas
- **Frontend:** Next.js 14, React, TypeScript, Tailwind CSS
- **Backend:** Supabase (PostgreSQL, Auth, Storage)
- **IA:** OpenAI GPT-4, Anthropic Claude
- **Pagamento:** Kiwify
- **Análise:** Google Analytics 4, Meta Pixel

### Personas Principais
1. **Ana (70%)** - Mulher 30-50 anos, frustrada com dietas
2. **Carlos (20%)** - Homem 35-55 anos, quer perder barriga
3. **Juliana (10%)** - Profissional de saúde, atualização

### Métricas-Chave

- **CAC Alvo:** R$ 30
- **LTV Alvo:** R$ 150-300
- **ROAS Alvo:** > 3.0
