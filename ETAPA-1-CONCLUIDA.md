## 📋 COMO TRABALHAR NA ETAPA 2

### Estrutura de Conversas com Roo

**❌ Não Fazer:**
```
"Crie toda a estrutura do projeto, configure tudo e 
implemente autenticação completa"
```
*Muito amplo, difícil de testar, alto risco de erro*

**✅ Fazer:**
```
"Sprint 1 - Dia 1: Criar estrutura do monorepo"

Tarefas:
1. Criar pastas apps/ e packages/
2. Inicializar Git
3. Criar package.json raiz
4. Testar estrutura

Critério de sucesso:
- tree -L 2 mostra estrutura correta
- git status funciona
- npm install sem erros
```
*Específico, testável, baixo risco*

### Fluxo de Trabalho

```
1. Escolher uma task do SPRINT-1-FUNDACAO.md
    ↓
2. Executar a task
    ↓
3. Testar conforme checklist
    ↓
4. Commit se passou nos testes
    ↓
5. Próxima task
```

### Exemplo de Conversa Ideal

**Usuário:**
