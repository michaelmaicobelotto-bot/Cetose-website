## 📖 COMO LER ESTE CHANGELOG

### Tipos de Mudanças

- **✨ Added** - Novas funcionalidades
- **🔄 Changed** - Mudanças em funcionalidades existentes
- **🗑️ Deprecated** - Funcionalidades que serão removidas
- **❌ Removed** - Funcionalidades removidas
- **🐛 Fixed** - Correções de bugs
- **🔒 Security** - Correções de segurança

### Versionamento

```
MAJOR.MINOR.PATCH

MAJOR: Mudanças incompatíveis (breaking changes)
MINOR: Novas funcionalidades (compatíveis)
PATCH: Correções de bugs (compatíveis)

Exemplo: v1.2.3
- 1 = Versão principal
- 2 = Funcionalidade nova
- 3 = Correção de bug
```

## 📝 COMO CONTRIBUIR COM O CHANGELOG

### Ao Adicionar Nova Funcionalidade

1. Adicione na seção `[Unreleased]` primeiro
2. Quando fizer deploy, mova para nova versão
3. Use o formato correto (✨ Added, 🔄 Changed, etc.)
4. Seja específico e claro
5. Inclua links quando relevante

### Exemplo de Entrada

```markdown
### ✨ Added
- Implementado chat com IA especialista em cetose (#123)
  - Suporte a perguntas sobre alimentos
  - Sugestões de receitas personalizadas
  - Integração com OpenAI GPT-4
  - Histórico de conversas salvo
```
